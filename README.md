# 用 Claude Code 自动投网申：方法整理

> 这是我用 Claude Code 投了几十家校招网申后总结的做法。用过的系统包括北森、Moka、飞书、智联、国聘、51job、各家银行自己的系统，以及 Workday、SuccessFactors、Greenhouse 等外企系统。这里只写方法，没有个人资料。

---

## 一、整体思路

一句话：**插件先一键填，Claude 再补空、纠错，推进到最后一个提交按钮前停下，最后由你自己点提交。**

几条原则：

- **资料只有一个来源**，就是 `profile.md`。Claude 只照抄，不编；缺的就问你，问过的答案记下来，下次不再问。
- **能用插件或直接填写解决的，就不让 AI 一步一步去点**。一步步点既慢又费 token。
- **登录、验证码、密码、证件号、隐私授权、最终提交**，这几样始终由你自己做。
- **每个招聘系统的规律都记进 `forms.md`**。同一套系统第二次就快很多：第一次摸清一套系统大约要 40 分钟，之后同系统大约 10 分钟。

## 二、要装的东西

| 工具 | 用途 | 说明 |
|---|---|---|
| Claude Code | 总指挥 | 已有 |
| Claude in Chrome 扩展 | 让 Claude 直接操作你日常用的 Chrome，已登录的网站可以直接用 | 在 Chrome 应用商店安装，登录同一个 Claude 账号；在 Claude Code 里输入 `/chrome` 连接，也可以启动时用 `claude --chrome`。显示"未连接"时，到 `chrome://extensions` 把扩展关掉再打开 |
| 牛客网申助手（Chrome 插件） | 一键填表，适配主流国内网申系统 | **先在牛客网把在线简历填完整**，插件从那里取数据 |
| （可选）jev-ultrafast | 速度更快、成本更低的浏览器 agent | 见第十一节，不装也能用 |

Claude in Chrome 给 Claude 的能力有：打开网页、读取页面和表单、点击、输入、上传文件（能传到隐藏的 file input）、在页面里运行 JS、截图。网申基本靠这几个就够了。

## 三、建一个资料文件夹

```
~/job-apply/
├── CLAUDE.md          # 给 Claude 的网申规则（第四节，直接复制）
├── profile.md         # 你的全部资料（唯一的事实来源）
├── answers.md         # 你认可过的问答：自我介绍、为什么选这个岗位、职业规划……
├── forms.md           # 每个招聘系统的规律和坑（Claude 每投完一家就更新）
├── applications.csv   # 投递记录：时间,公司,岗位,链接,状态,备注
├── 定制简历_日期.md    # 按岗位调整侧重点后的简历稿
└── materials/         # 简历 PDF/Word、证件照（多备几个尺寸，如 295×413）、生活照、成绩单、语言成绩单
```

建议对这些文件执行 `chmod 600`。

### profile.md 模板

按网申表的常见栏目来写。**格式就写成你希望在表里看到的样子**，例如日期统一写 YYYY-MM-DD，在读的写"至今"。

```markdown
# 基本信息
姓名 / 拼音名 / 性别 / 出生日期 / 民族 / 政治面貌 / 籍贯 / 户口所在地 / 现居住地 / 手机 / 邮箱 / 身高 / 体重 / 婚姻状况

# 求职意向
期望城市（按顺序）/ 期望岗位 / 是否服从调剂 / 期望薪资 / 到岗时间 / 信息来源（一般填"官网"或"其他"）

# 教育经历（从高中写起，很多系统要求必须有高中段）
学校（中文名 + 英文名 + 各系统里出现过的译名）/ 学历 / 学位 / 学习形式 / 院系 / 专业 / 起止时间 / GPA 或均分 / 专业排名 / 主修课程

# 实习·工作经历（每段：单位 / 部门 / 职位 / 地点精确到区县 / 起止 / 工作内容 / 离职原因 / 证明人及电话）
# 项目经历（名称 / 角色 / 起止 / 介绍 / 职责 / 成果）
# 在校经历 / 学生工作
# 获奖（名称 / 级别 / 等级 / 时间）
# 外语能力（考试 / 分数 / 日期）
# 资格证书（名称 / 发证机构 / 日期）
# 技能、兴趣爱好
# 自我评价（准备长短几版：50 字 / 200 字 / 500 字）

# 补充信息（Claude 问过你的问题按日期追加，下次直接用）
- 2026-xx-xx 「是否接受调剂」→ 是

## Local only（这一行以下的内容不发给第三方模型）
证件号码、家庭成员（关系 / 姓名 / 出生年月 / 单位 / 职务 / 政治面貌）、紧急联系人、
各份材料的文件路径，以及默认用哪一份
```

下面几条是踩坑后总结的，建议提前准备：

- **空白期**：不少系统会检查教育和工作经历之间**超过 6 个月的空档**，不补上就不让投。提前想好空档期怎么写，并写进 profile。
- **字数**：自我评价、实习描述最好准备几个长度的版本。很多字段只允许 20、50 或 100 字，**超出部分会被直接截掉，页面也不提示**。
- **地点**：很多系统要求实习地点选到区县，提前查好每段实习的办公地址在哪个区。
- **海外学校**：国内系统的学校库通常只认中文译名，而且不同系统的译名还不一样，用英文名一般搜不到。把你学校出现过的译名都写进 profile。

## 四、把规则交给 Claude（直接复制）

把下面这段存成 `~/job-apply/CLAUDE.md`，在这个目录里启动 Claude Code 时会自动读取。也可以直接让 Claude"记住这些规则"，写进它的记忆。

```markdown
# 网申规则

## 资料
- 所有资料只用 ~/job-apply/profile.md 里我写的内容，原样照抄，不翻译、不润色、不编造；不要从简历文件里自己提取补全。
- 表单有必填项而 profile 里没有：先把能填的全部填完，再一次性问我；我回答后，把答案按日期追加到 profile.md 的「补充信息」，同一个问题不要问第二次。
- 问答题先从 answers.md 里找我认可过的答案，再按岗位改写；新写的要先给我看，我确认后存进 answers.md。
- 「Local only」以下的内容（证件号、家庭成员等）不要写进任何发给外部服务的请求里。

## 选岗
- 我在 Chrome 里开着的岗位标签页 = 我已经选好的岗位，直接投。
- 你自己找到的岗位，投之前先列给我，等我确认。
- 投之前先查：applications.csv 里有没有投过；这家公司或这个项目每人限投几个；我已经用了几个。名额满了就不要填表。
- 每家公司只用一份简历（同公司多个岗位共用一份）。可以按岗位调整排序、侧重点和措辞，但事实不能改；定制稿写进「定制简历_日期.md」给我看。

## 填表流程
1. 先读 forms.md 里这个招聘系统的那一节。
2. 打开表单。遇到登录、扫码、短信验证码或滑块：把标签页切到前台，告诉我要做什么，然后等我。
3. 表单有「上传简历自动解析」而且表还是空的：先上传简历让它解析。已经填过的表不要再往解析框传文件，否则会覆盖已填内容。
4. 点牛客网申助手的「一键填写」。
5. 读出所有字段，列出必填但为空的项和填错的值（对照 profile 逐项核对，插件和简历解析都会出错），只补这些。
6. 需要逐块保存的表单，就一块一块保存；保存后回读核对，尤其是日期。
7. 一直推进到最后一个不可撤回的按钮（「确认提交 / 确认投递 / Submit」）前停下。保存、下一步、点「投递」打开确认框、进入预览页，这些都由你来做。
8. 汇报只写「每家还剩哪一步」，不要列长清单。

## 只能由我来做的
登录、密码、验证码 / 滑块 / 扫码、手写签名、证件号码、隐私协议和声明的勾选框、最终提交。

## 记录
- 投完在 applications.csv 里记一行（时间,公司,岗位,链接,状态,备注），状态填 submitted / filled-not-submitted / blocked。
- 把这次在这个招聘系统上验证过的规律和坑写进 forms.md（只写验证过的，不写猜测）。
```

**关于 Claude Code 的 auto 模式**：它的安全检查会把「下一步 / 保存 / 提交」这类点击判断成"未经确认的提交"并拦下。解决办法有两个：在对话里明确说"这几个岗位（逐个列出）你可以推进到预览页"，或者自己添加权限规则。

## 五、每次投递的流程

你只需要说一句："这几个标签页里的岗位帮我投，推进到提交前。" Claude 会：

1. 检查是否投过，以及还剩几个投递名额。
2. 读 `forms.md` 里对应系统的那一节。
3. 打开表单，遇到登录就叫你。
4. 如果是空表，先上传简历让它解析。
5. 点牛客插件的「一键填写」。
6. 读出全部字段，找出空着的必填项和错值，对照 profile 补齐、改正。
7. 问答题从 `answers.md` 里改写；缺的资料一次性问你。
8. 逐块保存，推进到预览页或确认框，截图核对。
9. 告诉你"X 公司：点『确认投递』即可"。
10. 你提交后，它在 `applications.csv` 记一笔，并更新 `forms.md`。

**建议每家公司单独开一个标签页。** 卡在验证码的那家先留着，另开标签页做下一家。

## 六、牛客插件的实际表现

- 一般能填 6～7 成，一次实测是 46/63 项。基本信息、教育经历、经历里的单位/职位/内容、自我介绍填得比较好。
- **经常漏填**：经历的**起止时间**、离职原因、户口所在地、爱好、应聘原因、求职意向、家庭成员、各种声明题。
- **经常填错**：国家选错；海外学校被填成手动输入的"其他"；经历没按时间排序。所以插件填完一定要让 Claude 逐项核对。
- 「补充填写」按钮基本没用，实测补了 0/12 项。
- 插件会把没填的字段标签涂成红色。这只是插件的提示，不是表单报错。
- 插件面板是封闭的 shadow DOM，Claude 按文字找不到它的按钮，要先截图再按坐标点。
- 有些页面不会自动注入插件。插件只有 activeTab 权限，有的网站要你先点一下工具栏里的插件图标才会生效；北森移动版页面上也不注入。遇到这种情况，就让 Claude 全部手动填。

## 七、让 Claude 填难填控件的要点

招聘网站大多用 Vue/React 加 Element、Ant Design 这类组件库。如果直接改输入框的 value，常常看上去填好了，保存时却是空的。这一节也可以直接发给 Claude 看。

**通用顺序**：先调组件自己的方法，其次模拟真实点击，再次用原生 setter 加 input/change 事件，直接改 value 基本无效。

- **文本框**：用 `HTMLInputElement` 或 `HTMLTextAreaElement` 的原生 value setter 赋值，再触发 input、change、blur 事件。textarea 必须这样做，否则换行会丢。
- **Vue 页面**：元素上的 `__vue__` 可以拿到组件实例，直接调用组件方法（比如选择器的 onChange）。这和手动操作走的是同一条路径，最稳。
- **下拉框**
  - 上一个下拉框没关就去点下一个，点击会落到弹出的选项上，造成误选。每选完一个就按 Esc 关掉。
  - 只认"这次点开后新出现的"选项，因为旧菜单常常还留在 DOM 里。
  - 虚拟列表（如 antd 4）打开时可能停在中间，要先滚到顶再找。
  - 有的组件选中后，值显示在一个 span 里，input.value 却是空的，核对时要看显示出来的值。
  - 带搜索的下拉框，有的要至少输入两个字才出现选项。
- **日期**：先分清是日面板、年月面板，还是 4 个下拉框（起年、起月、止年、止月）。很多控件没有"至今"，只能填当月；也有系统用特殊值表示至今，比如 9999-12-31。改了年份后月份可能被重置，最后要截图核对。
- **地区级联**：很多要求选到区县。有的要点名字**前面的圆圈**才算选中，点名字只会进入下一级；最后还要点弹层里的「确定」。
- **学校 / 专业联想框**：海外学校用中文译名搜索。库里没有的，选「其他」或「使用"xxx"作为我的学校」；有的输入框会把空格吃掉。专业库里没有的，选最接近的大类，再在备注里写全称。
- **同名字段多**（"名称""职务""开始时间"）：按区块定位，不要只靠"第 N 个"，否则容易填到别的区块，比如误写进家庭成员的出生日期。
- **字数上限**：先读字段的 maxLength，超出会被直接截掉，页面不提示。
- **上传文件**
  - 一个页面常常有好几个 file input。第 0 个往往是「简历解析」，证件照、生活照和附件在后面；传错位置会触发重新解析，覆盖整张表。
  - 组件拿到文件后会清空 input，工具可能报"没传上"，其实已经传了。等几秒，截图确认。
  - 一次传一个文件，间隔几秒。注意格式和大小限制：有的不收 PDF，证件照有的限制在 200K、512K 或 1M 以内。
- **后台标签页**：浏览器会给后台页面降速（动画帧不执行，定时器被限速），antd 的弹层、下拉框和日期控件在后台会失灵。切到前台再操作。
- **核对**：antd 表单可以对每个 `.ant-form` 的组件调用 `validate()`。这是纯前端校验，不发请求，能一次列出所有没通过的字段。预览页显示的是服务器上的数据，最可靠。
- **时区**：如果你人在海外，电脑时区不是北京时间，有的系统会把所有日期存成**前一天**。保存后要回读核对；出了问题，就让 Claude 用 CDP 把页面时区设成 `Asia/Shanghai` 再重填。
- **翻译插件**：沉浸式翻译这类插件会在英文页面加载几秒后插入中文，结果填进去的是中文。投英文表单前，先对该网站关掉自动翻译。
- **简历解析带进来的脏数据**：教育或经历错位、旧账号里的残缺条目，还有康熙部首这类看着像汉字其实不是的字符，都要改回 profile 里的原文。
- **Claude in Chrome 的输出过滤**：看起来像 Cookie、URL 查询串或 Base64 的内容会被替换成 `[BLOCKED]`。读值时让 Claude 把 `= & ? %` 替换掉，或者拆开输出。
- **页面里运行的 JS 超过约 45 秒会超时**：长任务放进后台 Promise，再分几次去取结果。
- **剪贴板**：不要让 Claude 用 pbcopy + ⌘V 往网页里粘贴。剪贴板是全机共享的，同时开着多个会话时，可能贴进别的会话复制的内容。

## 八、各招聘系统速查

| 系统 | 怎么认 | 要点 | 需要你做的 |
|---|---|---|---|
| **北森 Beisen** | `*.zhiye.com`，页脚写 Powered by Beisen | 「我的简历」（账号级）和「岗位申请表」不是同一张表，后者多一批必填项。同一租户投第二个岗位时会带出上一份申请的内容。输入框常常没有标签，AI agent 容易乱填，应改用直接填写。顶部第 0 个 file input 是解析框。老门户有电脑版和移动版两套模板，字段不同，两边都要补。有的会检查 6 个月空白期 | 登录；提交时的图片验证码；隐私勾选 |
| **Moka** | `app.mokahr.com` 或白标域名 | 账号里存的简历会自动带出。换简历会重新解析，覆盖教育和经历；只想加材料就用「上传附件」。下拉框是 sd- 组件，选中的值显示在 span 里。起止时间是 4 个下拉框。常见「1 个月内限投 N 个」 | 滑块或网易易盾验证 |
| **飞书招聘** | `*.jobs.feishu.cn` | 投递前必须登录；手机区号默认值可能不是 +86，要改 | 短信验证码 |
| **智联校招 / hotjob** | `*.zhaopin.com`、`xiaoyuan.zhaopin.com`、`wecruit.hotjob.cn` | 每个板块单独保存，按钮文字中间有空格。会带入智联账号里的残缺旧条目，要删掉。有志愿规则（几个单位、每个单位几个志愿、同单位要连续）。字数上限很低，而且不提示。hotjob 的学校库只有国内高校，输入时空格会被去掉。有的个人承诺要用手机扫码手写签名 | 扫码登录；手写签名 |
| **国聘** | `iguopin.com` | 「申请职位」可能是一键投递（直接用在线简历），所以要先把在线简历建完整。单位专属模板比通用简历多一大批必填项：高中段、专利、论文、家庭成员、证明材料压缩包（命名为"姓名+岗位名称"）。保存后列表不刷新，要重新打开页面 | 登录 |
| **51job 应届生** | `xyz.51job.com` | 分块编辑、分块保存。旧 51job 简历里的职位是职能分类，要改。日期没有「至今」 | 登录；「立即投递」 |
| **银行自建系统** | 各银行官网 | 普遍情况：每人限投 2～3 个；确认后不能撤回；要求有高中段；家庭成员必填；每块单独保存；证件照有尺寸要求。个别系统：基本信息保存后不能再改（会弹确认）；日期只能在面板上点选；刷新后勾选框会丢；后台页弹层失灵 | 登录（短信 + 图形验证码）；提交 |
| **Workday** | `*.myworkdayjobs.com` | 岗位接口见第九节 | 注册 / 登录 |
| **SuccessFactors** | `*.successfactors.*` | 申请页同时也是注册页。下拉框要逐字模拟键盘输入才会过滤。日期控件在 shadow DOM 里，要逐字输入 | 密码；邮箱一次性验证码；提交 |
| **Greenhouse** | `job-boards.*.greenhouse.io` | 下拉框是 react-select。提交后邮箱会收到 8 位验证码，输入后才算提交成功 | 验证码 |

## 九、查"哪些岗位能投"

不用一个个点开岗位页看要求。大部分招聘系统都有公开的岗位列表接口，可以让 Claude 直接拿 JSON 批量筛选学历、专业、城市和截止日期：

- **北森**：`POST https://<租户>.zhiye.com/api/Jobad/GetJobAdPageList`，body 里的 `PortalId` 从页面中取，返回结果含任职要求全文。
- **国聘全站**：`POST https://gp-api.iguopin.com/api/jobs/v1/list`，body 写 `{"page":1,"page_size":50,"nature":["115xW5oQ"],"job_name":"投资"}`。其中 nature 这个值代表校招；搜索条件只有 `job_name` 生效。返回结果里 `is_apply=true` 表示可以用国聘在线简历直接投。
- **智联校园**：`https://xiaoyuan.zhaopin.com/search/index?query=关键词&pageIndex=1` 是服务端渲染的，页面里的 `window.__INITIAL_DATA__` 就有岗位列表。**卡片上写的学历要求不可信**，一定要打开岗位页读任职资格。
- **飞书招聘**：先 `POST /api/v1/csrf/token`，再 `POST /api/v1/search/job/posts`，请求头带上 website-path、portal-channel 和 x-csrf-token。
- **hotjob**：`POST /wecruit/positionInfo/listPosition/<SU编号>?iSaJAx=iSaJAx`；详情接口里的 `applyNumByProject` 是每人可投数量。
- **Workday**：`POST https://<租户>.wdN.myworkdayjobs.com/wday/cxs/<租户>/<站点>/jobs`，body 写 `{"searchText":"graduate"}`。
- **秋招汇总表**（如腾讯文档）导出成 xlsx 后，链接列经常错位，要用在线表里的超链接。公众号原文要先核对标题再用。

## 十、省钱、省时间

- **先用牛客插件填，Claude 只补漏和纠错**，比让 Claude 一个字段一个字段地填快得多，也省 token。
- **输入框没有标签的表单（北森最典型），不要交给"自己看页面、自己决定点哪里"的 AI agent**。它分不清字段，会把证件号填成随便一个数字；在报错提示时隐时现的页面上，它会反复思考却不动手。我有一次一步没动就烧掉了 100 多万 token。这种表单让 Claude 按区块和位置定位，直接填写。
- **投之前先看名额**。有一次整张表都填完了，才发现这个项目已经投满 3 个，白填了。
- **每遇到一个新系统，都让 Claude 写进 `forms.md`**。同一系统第二次投，大约能快 4 倍。

## 十一、（可选）jev-ultrafast

`browser-use/jev-ultrafast` 是 GitHub 上的开源浏览器 agent。它把页面转成一张元素表，每一步只选一个动作和一个元素，每步只要零点几秒，比 Claude 自己截图再点快，也更便宜。需要准备：

- Chrome 打开远程调试：在 `chrome://inspect/#remote-debugging` 打开 "Allow remote debugging for this browser instance"，第一次连接时在弹窗里点 Allow。
- 模型 key：文本模型用 OpenRouter；决策模型用它自带的托管服务，或者任意 OpenAI 兼容的模型（比如 DeepSeek）。
- 我让 Claude Code 给它包了一个命令行工具，包括 fields（列出所有字段和空着的必填项）、fill、select、date、click、upload、shot（截图）。这些直接填写的命令不调模型，没有花费。你可以让 Claude Code 按这个思路给你写一个。

其实只用「牛客插件 + Claude in Chrome」就够了。投递量很大、还想再省 token 时，再考虑 jev。
